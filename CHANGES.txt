MineNight All-in-One 1.5.2
- Defaults to disabled block drops, and suppresses block item spawns immediately after break/explosion events.
- New optional built-in basic AutoTotem pattern monitor. Not the full TotemGuard plugin and no packet-level detection. Alerts only; no bans.
- Config: plugins/MineNightAllInOne/performance/config.yml (block-drops.disabled: true)
- Config: plugins/MineNightAllInOne/totemmonitor/config.yml
- Hotbar IP: plugins/MineNightAllInOne/tab/config.yml -> actionbar.text
- If a saved config still has disabled: false, set it to true or run /noblockdrops on.
- Falling blocks, custom plugin item spawns, player inventory drops are not universally suppressed.
- Test on a backup server.

v1.7.6
- Join teleport to the configured practice spawn is silent; /spawn still shows its confirmation.
- Entity cleanup on successful teleport, disconnect and respawn for tracked player-owned
  placed entities (including crystals), launched projectiles (including pearls) and
  manually dropped items. Does not remove other players' entities or scan entire worlds.
- Unattributed XP orbs are not deleted: Minecraft/Paper does not reliably expose an owner
  for all XP orbs, and deleting nearby orbs could steal other players' XP.
- Default item despawn changed to 10 seconds (200 server ticks). Existing config values
  of 15 seconds are upgraded to 10; custom non-15 values are retained.
- Bounded owner entity IDs; pruning only runs while entities are tracked.

MineNight All-in-One 1.7.8
- Added a horizontal spawn-border rule based on the protected schematic footprint.
- Players can move freely inside spawn; touching the outermost border blocks or crossing outside returns them to the configured practice spawn.
- /tpa and /tpahere arrivals are still allowed; players are returned when they touch the border or try to walk out.
- Border detection is event-driven and only checks block-coordinate changes; no repeating task or world/entity scan.
- Staff with schematic admin permission and Schematic Staff Mode are exempt.
